# Assignment 2 – Cycle Detection in Linked List

## Aim
To detect a cycle in a linked list and identify the starting node of the cycle using different approaches.

## Programs

1. Cycle Detection Using HashSet
2. Cycle Detection Using Floyd's Cycle Detection Algorithm
3. Find Start of the Cycle

## Time Complexity

| Approach | Time | Space |
|----------|------|-------|
| HashSet | O(n) | O(n) |
| Floyd's Algorithm | O(n) | O(1) |
| Find Start of Cycle | O(n) | O(1) |

## Learning Outcomes

- Understand linked list traversal.
- Learn cycle detection techniques.
- Understand Floyd's Tortoise and Hare algorithm.
- Learn how to find the starting node of a cycle.
